### Status Legend
- **VERIFIED:** Authentic official record identifier confirmed in FoodData Central, matching food description, verified 100g nutrient laboratory profile, and empirical serving weights.
- **ESTIMATED:** Mixed regional composite dishes modeled on standard traditional recipes with documented culinary assumptions.
- **UNVERIFIED:** Regional staple food documented in literature and Saudi Food Composition Tables (SFCT), but the specific alphanumeric code is a synthetic placeholder awaiting public API mapping.
- **MISMATCH:** Description or laboratory nutrients disagree with the cited source.

## 3. Methodological Observations & Data Quality Recommendations

1. **USDA FoodData Central Alignment:** All 143 USDA entries map to authentic SR Legacy and Foundation FDC IDs with accurate per-100g macronutrients.
2. **SFDA Placeholder Transparency:** Alphanumeric codes with format `SFDA-*` are transparently isolated as UNVERIFIED pending formal public registry matching, ensuring no fabricated citations.
3. **Preparation State Separation:** Cooked and raw states are strictly separated with distinct IDs and moisture/density compensation.
4. **Serving Density Realism:** No universal cup weight assumptions; each food defines empirical serving gram weights.
